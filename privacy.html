プライバシーポリシー

「AI技術を1分で 動画運用」（以下、本アプリ）は、運営者が自分の YouTube チャンネルを管理するための個人用ツールです。

取得する情報

本アプリは、Google アカウントでの許可（OAuth）を通じて、許可されたチャンネルについて次の情報だけを扱います。

  • チャンネルの ID・名前などの基本情報
  • 動画のアップロード、公開設定、字幕、サムネイル、再生リストの操作に必要な情報

使い方

取得した情報は、運営者自身のチャンネルへの動画投稿と管理にだけ使います。広告、分析目的の販売、第三者への提供には使いません。

保存と共有

認証情報は運営者の手元のコンピュータにだけ保存し、外部のサーバーには送りません。Google のデータを第三者と共有することはありません。

Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

許可の取り消し

許可はいつでも Google アカウントのサードパーティ アクセスから取り消せます。
